## 🔴 Главная проблема: Изображения (40 MB)

### Текущие размеры:
- `bad-photo-example.jpg` - **1.9 MB** 😱
- `liza.jpg` - **1.0 MB**
- Множество изображений по 600-800 KB

### Решение:

#### Вариант 1: Автоматическая оптимизация (рекомендуется)

Используйте скрипт `optimize-images.sh`:

```bash
# Установите ImageMagick (если еще не установлен)
brew install imagemagick

# Запустите оптимизацию
chmod +x optimize-images.sh
./optimize-images.sh
```

Скрипт:
- Создаст резервную копию в `public/images-backup`
- Уменьшит качество до 75% (визуально незаметно)
- Ограничит ширину до 1200px
- Удалит метаданные

**Ожидаемый результат:** 40 MB → 8-12 MB (70-80% экономии)

#### Вариант 2: Онлайн сервисы

1. [TinyPNG](https://tinypng.com) - загрузите изображения
2. [Squoosh](https://squoosh.app) - Google инструмент
3. [ImageOptim](https://imageoptim.com/mac) - Mac приложение

#### Вариант 3: WebP формат (лучшее сжатие)

Конвертируйте JPG → WebP:

```bash
# Установка
brew install webp

# Конвертация
find public/images -name "*.jpg" -exec sh -c 'cwebp -q 80 "$1" -o "${1%.jpg}.webp"' _ {} \;
```

Затем обновите код для использования WebP с fallback на JPG.
